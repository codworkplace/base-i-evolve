# BS-Evolve
Платформа оценки и развития профессиональных компетенций сотрудников.

## Возможности MVP
- Выбор роли (Менеджер отдела продаж)
- Карта компетенций (7 ключевых навыков)
- Диагностический срез
- Отчет с рекомендациями

## Запуск
Установка зависимостей:
pip install -r requirements.txt

Запуск API:
python -m app.main

Запуск UI (в другом терминале):
streamlit run app/ui.py

## Технологии
Backend: FastAPI

Frontend: Streamlit

LLM: будет подключен
